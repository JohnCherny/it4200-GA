How the counter finder works

Matchups are calculated by the class API using Generation 6+ type effectiveness. Recommended counters have a super-effective same-type attack. Defensive resistance or immunity ranks higher; attack strength breaks ties. Movesets, abilities, stats, held items, and alternate forms aren't considered.
